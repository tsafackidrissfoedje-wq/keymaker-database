The SuperVAG KEY is a product of the HR CARSOFT s.r.o. company.

To learn more please visit the official website:

 

http://www.carsoft.cz

 

 

The SuperVAG KEY is able to read the image file from a vehicle via the OBDII interface.

Having the image file it is possible to make a key with Tango. After Tango generates a new file, upload it back to the vehicle using SuperVAG KEY tool.
