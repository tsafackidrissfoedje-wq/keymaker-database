Image generator for Mercedes Benz C, E, G -class 1996-1999.

 

Usage                          

Generate a key. Turn ignition on with the generated key and run engine.

 

Note                            

•Image generator allows to make a choice of key's number in range 1...8. It is necessary to choose the number that not jet used in the car.

 It is common situation that all cars have already used positions 1...3, therefore avoid to make a key in range 1...3. Besides, it is a good

 practice to observe used keys via diagnostic software.

 

•Sometimes if strength of the radio field between a transponder and an immo is weak, the immo isn't able to learn the key.

 

•In case a car doesn't start an engine, you should make a key with a keymaker.

 

•A key generated with the Image Generator isn't blocked and it is possible to clear it.
