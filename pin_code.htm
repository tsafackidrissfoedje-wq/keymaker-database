Renault PIN code calculator

 

Some old models equipped with IR (Infra Red) remote key fob to control door locks and immobilizer. In case the IR does not operate you can start a vehicle using PIN code and carry it to workshop.

PIN code have been calculated from a code number that can be found in a key fob. The code number may consist of digits, letters, all depends on a model of a vehicle.
