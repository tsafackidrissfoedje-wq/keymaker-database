Smart Keys for Toyota and Lexus

 

See Toyota RX 350 Smart Key example

 

Toyota and Lexus have equipped cars with the Smart Access since 2005y.

The Smart Access system contains the following units:

·Smart Key ECU (Certification ECU). Operations with a key on low and high frequency, ignition ON-OFF, central lock.
·Steering lock unit. Blocking of the steering column.
·ID CODE ECU. Gateway between Smart Key ECU - Steering lock unit - Motor ECU

 

Smart Keys are kept in the Smart Key ECU.

The Smart Keys are of various types and may be DST+, DST40, DST80, DST-AES depending on a car model and production year.

These keys may be identified with the Page1. Tango maker displays the expected key type, that depends on the dump.

 

Key Matching

·Unused key can be matched with a common diagnostic procedure. The procedure requires at least one valid key that switches ignition ON. After procedure complete the unused key becomes used, remote functions are active.
·Unused key can be matched with Tango keymaker. Remote functions are inactive, the key becomes used.
·Used key can be matched with "reset" operation. Remote functions are active.
·Used key can be matched with Tango keymaker. Remote functions are inactive.

 

The keymaker is useful in the "lost keys" case. The keymaker can make a valid key using any used key. This valid key can switch ignition ON and allows to match an unused key.

It is a good idea not to use unused keys to make the first valid key, because of this key never will have remote features. Instead it is common practice to use old used keys.

In case an immo expects a key with Page1 equal to 94 or D4, it is possible to use common TIRIS 4D (e.g. ID60, ID63...) or TPX2.

 

Reset

The reset procedure is been carried out with diagnostic equipment. In some cases this procedure fails. It may be a result of non original parts of the Smart Key Access system, damaged memory etc.

In this case it is a good idea to make a valid key using the keymaker.
